# 🌐 Fratak Translator

A simple cross-platform translation app built with **.NET MAUI** and **C#**.

---

## 🚀 Features

- 🌍 Translate between multiple languages
- 🔄 Swap source and target languages
- ↔️ RTL/LTR text support
- 📋 Copy translated text
- 📤 Share translation result
- 🎞️ Simple UI with animations

---

## 🛠️ Tech Stack

- .NET 8 / .NET MAUI
- C#
- XAML
- Newtonsoft.Json

---

## 📱 Platforms

- Android
- iOS
- Windows
- MacCatalyst

---

## 📦 Run Project

```bash
git clone https://github.com/Mohammad-Amin-Nazeri/TransletaApp-Maui.git
cd TransletaApp-Maui
```

Open `TransletaApp.sln` in Visual Studio and run.

---

## ⚠️ Notes

- Uses an online translation API
- No test project yet
- Simple UI-based structure (no MVVM)
