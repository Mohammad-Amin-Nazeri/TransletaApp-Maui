# 🇬🇧 English

## About

**Fratak Translator** is a cross-platform translation application built with **C#** and **.NET MAUI**.

The project focuses on a clean translation experience while demonstrating practical cross-platform development, multilingual language handling, RTL/LTR UI support, and platform-aware design.

## ✨ Features

- 🌍 Source and target language selection
- ↔️ RTL/LTR support for Persian, Arabic, Hebrew, Urdu, and Pashto
- 🔄 Source/target language switching
- 📋 Copy translated text
- 📤 Share translation results
- 📱 Responsive and adaptive UI
- 🔤 Custom fonts and visual resources
- 🌐 Online translation service integration

## 🏗️ Architecture

The project uses the **.NET MAUI Single Project** architecture, keeping shared application code and UI together while providing platform-specific implementations where required.

```text
TransletaApp/
├── App.xaml
├── AppShell.xaml
├── MainPage.xaml
├── MainPage.xaml.cs
├── MauiProgram.cs
├── translateClass.cs
├── Platforms/
│   ├── Android/
│   ├── iOS/
│   ├── MacCatalyst/
│   └── Windows/
└── Resources/
    ├── Fonts/
    ├── Images/
    └── Splash/
```

## 🛠️ Technology Stack

- **C#**
- **.NET 8**
- **.NET MAUI**
- **XAML**
- **Newtonsoft.Json**
- MAUI Resources and custom fonts

## 🎯 What This Project Demonstrates

- Cross-platform application development with a shared codebase
- Multilingual UX and language-code mapping
- RTL/LTR-aware interface design
- Platform-specific integration within .NET MAUI
- Resource-based UI customization

# 🇮🇷 فارسی

## معرفی

**Fratak Translator** یک اپلیکیشن ترجمه چندسکویی است که با **C#** و **.NET MAUI** توسعه داده شده است.

تمرکز پروژه روی یک تجربه ساده و کاربردی برای ترجمه، در کنار پیاده‌سازی قابلیت‌های مهم توسعه Cross-platform، مدیریت زبان‌های مختلف و پشتیبانی از رابط‌های **RTL/LTR** است.

## ✨ قابلیت‌ها

- 🌍 انتخاب زبان مبدأ و مقصد
- ↔️ پشتیبانی RTL/LTR برای فارسی، عربی، عبری، اردو و پشتو
